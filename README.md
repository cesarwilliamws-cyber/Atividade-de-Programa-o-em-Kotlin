# Atividade-de-Programa-o-em-Kotlin
Este repositório contém a resolução de 10 exercícios práticos desenvolvidos em Kotlin

# Conteúdo 
Questão 1: Inversão de elementos de um array utilizando while.

Questão 2: Busca de código de transação utilizando break.

Questão 3: Array de temperaturas e cálculo da média semanal.

Questão 4: Array com step 2 e índices pares.

Questão 5: Iteração de tarefas utilizando withIndex().

Questão 6: Matriz 3x4 e soma dos elementos de cada linha.

Questão 7: Criação de matriz transposta.

Questão 8: Matriz 4x4 e soma da diagonal principal.

Questão 9: Matriz 3x3, continue e soma dos valores positivos.

Questão 10: Matriz de notas, aprovação dos alunos e média geral da turma.

# Objetivo
Praticar arrays, matrizes, estruturas condicionais, laços de repetição e operações matemáticas.
